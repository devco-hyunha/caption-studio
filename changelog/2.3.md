# 2.3.x

README 1단계: `caption.js` Subtitle 도메인을 `modules/subtitle/`로 분리.

---

## 2.3.0 — 2026-09-02

### Changed

- `Subtitle` 도메인을 `public/js/modules/subtitle/`로 분리
  - `index.js` — `subtitleModule()`, `initialize({ Interface, Sheet, i18n })`
  - `header.js`, `valid.js`, `encode.js`
  - `convert/` — `srtHelpers.js`, `smiHelpers.js`, `index.js` (`export default { srt: toSrt, smi: toSmi }`)
  - `importHandlers.js` — text · smi · srt 가져오기, charset 설정 (`encoding`)
  - `export/` — `exportHandlers.js`, `formatExportData.js`, `constants.js`
- 공개 API — `header`, `encode`, `converters` + `initialize()` 이후 `import` / `export`
  - `toSrt` / `toSmi` / `valid`는 모듈 내부 전용
- `caption.js` — `Subtitle.*` 인라인 구현 제거, `subtitle` 모듈 import·호출로 전환
  - `initializeDomainModules()` → `subtitle.initialize()`
  - 시트·편집기 — `subtitle.encode`, `subtitle.header`, `subtitle.converters` 직접 호출
  - 레거시 IIFE 주석·`var Subtitle = {}` 제거
  - `Fn.Encode*` 제거 → subtitle import/export로 이전
- `getActionContext` — `runAction`용으로 `import` / `export`만 노출 (`subtitle` 전체 제외)
  - `Fn.Format`, `Fn.Language`는 유지
- `index.html` — `data-action` 경로 정리
  - 탭 init: `import.*` · `export.*`
  - import charset: `import.encoding.smi` · `import.encoding.srt`
  - export charset: `export.encoding.smi` · `export.encoding.srt` · `export.encoding.vtt`
  - export smi/srt 선택: `export.sheetFormat.json` · `export.sheetFormat.excel`
- subtitle 모듈 jQuery 제거 (핸들러·`encode`)
  - `encode.js` — native DOM + `toElement()`
  - `importHandlers` / `exportHandlers` — `bindEvent`, `querySelector` 기반
- `public/js/modules/utils/dom.js` 추가 — `bindEvent`, `parseEvent`, `toElement`, `isJQuery`
- import/export 핸들러 리팩터
  - smi/srt import — config 기반 `createFileImportHandler`
  - export 포맷별 — config 기반 `createExportHandler`
  - import GA — 파일 읽기 성공 후에만 전송
  - charset / sheetFormat — `encoding`, `sheetFormat` 하위 객체 (`encode.js` HTML 정규화와 구분)
- 변환·export 가공 리팩터
  - Timeline 배열 destructuring (`{ start, end, text, memo = '' }`)
  - `formatExportData` — 불필요한 `clone` 제거
  - `smiFromSrtArray` — 입력 mutation 제거, `prevEnd` 정리
  - `smiFromSmiString` — DOM `<sync>` 변수 `sync`, `start` 유효성 검사 명시화
  - `encode` — 시그니처 단순화, `slice` 사용
  - import `fileReader.onload` — 화살표 함수
- `converters` — `convert/index.js`에서 단일 정의, import/export/caption 공유

### Fixed

- SMI/SRT import 인코딩 — `readAsText` 시점에 `storage.get('smiEncode')` / `storage.get('srtEncode')` 사용 (jQuery `.data('value')` 의존 제거)

### Note

- **2.3.0 범위** — subtitle JS 모듈 분리. export 실파일(PHP) 검증은 서버 환경 필요 — 로컬은 Network payload로 대체
- `Fn.Format` / `Fn.Language` — `caption.js` 유지, 추후 `settings` 도메인 분리 예정
- `dom.js`의 `isJQuery` / `toElement`, `encode`의 jQuery 입력 — caption jQuery 제거 이후 정리
- `caption.js` jQuery 이벤트 전반 — 추후 도메인 분리·`bindEvent` 전환 예정

## 2.3.1 — 2026-09-03

### Changed

- 자막보내기(SMI/SRT/VTT/JSON/Excel)를 서버 POST 없이 클라이언트 Blob 다운로드로 전환
  - `exportHandlers` — `clientDownload`로 본문 생성 → 인코딩 → `downloadBytes`
  - 텍스트 포맷 — `build/buildFile.js` (`buildSmi` · `buildSrt` · `buildVtt` · `buildJson`)
  - Excel — `build/buildExcel.js` + `build/zipStore.js`로 최소 xlsx(STORE ZIP) 생성
  - 레거시 인코딩(UTF-8 · EUC-*) — vendored `iconv-lite` + `download/iconv.js`의 `encodeText`
- `export/` 구조 정리
  - `build/` — 파일 내용 생성 (`buildFile` · `buildExcel` · `zipStore` · `constants`)
  - `download/` — 인코딩·저장 (`iconv` · `downloadBytes`)
- `download/*.php` 제거 (`smi` · `srt` · `vtt` · `json` · `excel` · `xlsxWriter`)
- `index.html` — export 폼 `action`/`method` 및 Excel caption textarea 제거
- `README.md` — `download/` 서버 내보내기 안내 제거

### Changed

- `public/js/modules/env.js` — `PRODUCTION_HOST`, `isProduction()` (analytics · ads 공유)

  - `downloadBytes` 호출 후에만 전송 (변환·인코딩 실패 시 미전송)
- 개발 환경에서 GA · 네이버 로그분석 · AdSense 차단 (`isProduction()` 허용 목록)
