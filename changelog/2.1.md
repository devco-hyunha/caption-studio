# 2.1.x

README 1단계: `caption.js` i18n locale 모듈 분리.

---

## 2.1.0 — 2026-08-28

### Changed

- `caption.js` 상단 i18n 사전(~360줄)을 `public/js/modules/i18n/`로 분리
- ES module로 locale 로드, `caption.js`는 `type="module"`로 실행

| 파일 | 내용 |
|------|------|
| `public/js/modules/i18n/kr.js` | KRCC locale |
| `public/js/modules/i18n/en.js` | ENCC locale |
| `public/js/modules/i18n/jp.js` | JPCC locale |
| `public/js/modules/i18n/i18n.js` | locale 집계·export |
| `public/js/caption.js` | 인라인 `i18N` 제거, `import` 연동 |
| `index.html` | `caption.js`를 `type="module"`로 로드 |

### Note

- UI 동작·`i18N[Sheet.Language][key]` 사용 방식은 유지
- `eval` 제거, `i18n.t()` API 전환은 추후 작업

---

## 2.1.1 — 2026-08-28

### Changed

- `i18n.js`: factory API (`getLanguage`, `setLanguage`, `getLocale`, `t`)
- `caption.js`: `i18N[...]` → `i18n.t()`, `Fn.Language`에서 `i18n.setLanguage` 동기화
- `Interface.I18n`: `getLocale` / `t` 기반 DOM 갱신
- `VERSION`·About UI 버전 **2.1.1** 동기화 (2.1.0에서 About `2.0.2` 누락 보정)
- `en.js`: 들여쓰기 `kr.js` / `jp.js`와 동일하게 정리

| 파일 | 내용 |
|------|------|
| `VERSION` | `2.1.1` |
| `index.html` | About `<dd>` `2.0.2` → `2.1.1` |
| `public/js/modules/i18n/i18n.js` | `setLanguage` locale 검증, `getLocale` / `t` 추가 |
| `public/js/modules/i18n/en.js` | 들여쓰기 정리 |
| `public/js/caption.js` | `i18n` 인스턴스 사용, `Fn.Language` / `Interface.I18n` 연동 |

### Note

- 2.1.0 release 시 `VERSION`만 갱신되고 About UI는 `2.0.2`로 남아 있었음 → 2.1.1에서 함께 맞춤
- `Sheet.Language`는 export 등 비-i18n 용도로 유지
- `eval` 제거는 추후 작업
