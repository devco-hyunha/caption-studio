## 2.1.0 — 2026-08-28

### Changed

- `caption.js` 상단 i18n 사전(~360줄)을 `public/js/modules/i18n/`로 분리
- ES module로 locale 로드, `caption.js`는 `type="module"`로 실행

| 파일 | 내용 |
|------|------|
| `public/js/modules/i18n/kr.js` | KRCC locale |
| `public/js/modules/i18n/en.js` | ENCC locale |
| `public/js/modules/i18n/jp.js` | JPCC locale |
| `public/js/modules/i18n/i18n.js` | locale 집계·export |
| `public/js/caption.js` | 인라인 `i18N` 제거, `import` 연동 |
| `index.html` | `caption.js`를 `type="module"`로 로드 |

### Note

- UI 동작·`i18N[Sheet.Language][key]` 사용 방식은 유지
- `eval` 제거, `i18n.t()` API 전환은 추후 작업
