## 2.4.0 — 2026-09-03

### Changed

- `Player` · `Video`를 `public/js/modules/video/`로 분리
  - `player.js` — `createPlayer({ ui, sheet, i18n })` — video.js 인스턴스·소스·오버레이 (모듈 내부 전용)
  - `index.js` — `videoModule()` · `initialize({ Interface, Sheet, i18n })` 후 공개 API
- 공개 API 소문자 — `init` · `fileCheck` · `toggle` · `volume` · `currentTime`
  - `caption.js` `Video` 별칭 제거, Shortkey · ready는 `video.*`
  - `data-action="video.fileCheck"`
  - 미사용 `VolumeUp` / `VolumeDown` 제거 (단축키는 `volume()` ±0.1)
- 오버레이 자막 클래스 `.print` → `.current-text`
- video 모듈 jQuery 제거 (`bindEvent` · `toElement` · `querySelector`)
  - `caption.js` `Interface.Wrap` · `fileCheck` 인자 · `sheet.Panel`은 `toElement`로만 수신
- 영상 로드 타입은 활성 `.tab-panel.on`의 `data-type` + 패널 안 `input`
- `player.load(type, src)` — youtube/vimeo/url/file은 player 객체에서 제외
- `player`에서 `target` · `html` · `timeTrigger` 제거
- `play` / `pause` / `paused` 래퍼 제거 — `toggle`이 `interface`를 직접 호출

### Fixed

- `currentTime(0)`이 getter로 처리되던 문제
- `refresh()` — `interface`가 있을 때만 `dispose`, 아니면 `element.remove`
- 로드 실패 후 `player.interface.on` 호출 제거, `#wrap.empty` 복구
- `subtitle-visible` 복원 — 저장값으로 `overlap` 설정 (미저장 시 HTML 기본값)
