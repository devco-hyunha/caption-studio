# 2.8.x

작업 목표 1 (모듈 분리): `caption.js` 부트스트랩 잔여 정리 · `settings` · `bootstrap`.
작업 목표 2 (구조): 도메인 라이프사이클 `configure` / `mount`, 셀 타깃 판별 공통화.

## 2.8.0 — 2026-09-06

### Added

- `public/js/modules/settings/`
  - `createSettings(context)` — `format` · `language` (`data-action="settings.*"`)
  - `format.js` / `language.js`
- `public/js/modules/index.js` — `bootstrap()`
  - 도메인 생성 · `configure` · `mount`
  - `{ onFontsActive }` 반환 (WebFont `active`)
- `public/js/modules/sheet/helpers/targets.js`
  - `isTextTarget` / `isTimeTarget`
  - `sheet.isTextTarget` / `sheet.isTimeTarget` getter

### Changed

- `caption.js` — ready · WebFont만 유지 (jQuery · `Fn` 제거)
- 도메인 공개 API: `initialize` → `configure`, `init` → `mount`
  - Shortcuts 엔진 `start` / `stop`은 유지 (`shortkey.mount` 내부에서 `start`)
- `subtitle` — `createSubtitle(context)` 팩토리 (`configure` 제거)
- `index.html` — `data-action="settings.format|language"`
- UI context — `Fn` → `settings`
- shortkey · sheet 호출부 — `TEXT_TARGETS.includes` 등 → `sheet.isTextTarget` / `isTimeTarget`
- 템플릿 리터럴 — 보간이 필요한 문자열 연결만 정리
- `==` / `!=` → `===` / `!==` (`== null` / `!= null` 제외)

### Removed

- `public/js/modules/shortkey/targets.js` (sheet helpers로 이전)

### Docs

- README: `bootstrap` · `settings` · 목표 상태
- CHANGELOG / VERSION / About `2.8.0`

### Note

- **선택:** `dialog.open`의 `ui.layer`와 `.dialog.on` 정합 후 shortkey 가드 단일화
- `lib/jquery` 제거는 후속 (앱 전역 jQuery 의존)
