# 2.8.x

작업 목표 1 (모듈 분리): `caption.js` 부트스트랩 잔여 정리 · `settings` · `bootstrap`.

## 2.8.0 — 2026-09-06

### Added

- `public/js/modules/settings/`

  - `format.js` / `language.js`

- `caption.js` — ready · WebFont만 유지 (jQuery · `Fn` 제거)
- 도메인 공개 API: `initialize` → `configure`, `init` → `mount`

- `index.html` — `data-action="settings.format|language"`
- UI context — `Fn` → `settings`
- shortkey · sheet 호출부 — `TEXT_TARGETS.includes` 등 → `sheet.isTextTarget` / `isTimeTarget`
- 템플릿 리터럴 — 보간이 필요한 문자열 연결만 정리
- `==` / `!=` → `===` / `!==` (`== null` / `!= null` 제외)

### Removed

### Docs

## 2.8.3 — 2026-09-07

브랜치: `feat/sheet-tabs`

다중 시트 데이터 모델(`sheets` / `active`)을 React 기준선으로 선반영한다.
바닐라 탭·export 시트 UI는 React에서 재구현할 예정이라 **interim 숨김**.
SMI Class/STYLE은 UI `locale` → 구 `KRCC`/`ENCC`/`JPCC` 프리셋으로 호환 유지.

### Added

- `sheet/tabs/` — 다중 시트 문서 · Footer 탭 CRUD · 탭명 검증(`A-Za-z0-9_`)
- `normalizeSubtitleTemp` — 구 `Timeline[]` → `{ version, active, sheets }` 승격
- 저장 키 `subtitleSheets` (레거시 `SUBTITLE_TEMP`는 읽기 전용)
- i18n 키 — 탭 추가/삭제/이름 규칙 · SMI 필드
- `subtitle/export/sheetPicker.js` — 시트 선택·SMI 메타 (UI interim 숨김)

### Changed

- UI 언어 키 `KRCC`/`ENCC`/`JPCC` → `ko`/`en`/`ja`, 저장 키 **`locale`** (`language`는 레거시 읽기 전용)
- `settings.language` — UI i18n만 (시트 language / SMI Class 분리)
- interim: SMI export Class/STYLE = UI `locale` → `KRCC`/`ENCC`/`JPCC` 프리셋
- interim: 시트 Footer · export 시트 선택 · SMI Class/Name/lang 입력 UI `hidden`
- export 파일명 기본값 비움 · 미입력 시 `caption`
- `editHistory` — 탭별 스냅샷용 `getState` / `setState`
- `#new-sheet` — 활성 탭 timelines만 초기화 (탭 구조 유지)
- 마지막 시트 삭제 — 내용 초기화 confirm
- 기본·자동 탭명 `sheet1` / `sheet2` …

### Fixed

- SMI 프리셋 JPCC `lang` `en-US` → `ja-JP`
- mount 시 `ensureSheetsLoaded`로 구 저장본 선로드
- 탭 전환 후 `convert`/`render` 다음에 스크롤 복원
- `sheet.tabs.persistActiveView` 인자 누락으로 autoSave 실패
- 탭명 편집: Enter 저장 · Esc/focusout 취소 · 입력 중 valid만
- 탭명 `contenteditable` 입력 시 shortkey가 시트 `edit.on`을 켜던 문제
