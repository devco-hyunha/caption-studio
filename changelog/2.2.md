# 2.2.x

README 1단계: `caption.js` 범용 유틸을 `modules/utils/`로 분리.

---

## 2.2.0 — 2026-08-31

### Changed

- `caption.js` 하단 유틸·프로토타입 확장을 `public/js/modules/utils/utils.js`로 분리
- zero-pad: `.zf()` 프로토타입 → `padZero()` (`String.padStart`)
- IE용 `Array.find` / `findIndex` 폴리필 제거 (IE 지원 종료 이후 불필요)
- 미사용 `Date.prototype.format` 제거

| 파일 | 내용 |
|------|------|
| `VERSION` | `2.2.0` |
| `index.html` | About `2.2.0` |
| `public/js/modules/utils/utils.js` | `clone`, `capitalize`, `extend`, `padZero` |
| `public/js/caption.js` | utils import, 인라인 유틸·폴리필 제거 |

### Note

- `Toast`는 UI(jQuery 의존)라 utils에 포함하지 않음 — 추후 UI 모듈 분리

---

## 2.2.1 — 2026-08-31

### Changed

- `Fn.Data` / `Fn.Log` / `Fn.Hour` / `Fn.Second`를 `modules/utils/`로 분리하고 API 전환
  - `storage.get` / `set` / `remove`
  - `editHistory` — `index`, `entries`, `prev`, `next`, `push`, `clear` (`utilsModule()`)
  - `formatTimecode`, `parseTimecode`, `splitTimecode`, `timePartsToMs`
- `Sheet.Edit.TimeControl` 시간 계산을 `time.js`로 통합
- `utils.js` → `object.js` / `string.js` 분리, `index.js`에서 `utilsModule()`로 통합 초기화

| 파일 | 내용 |
|------|------|
| `VERSION` | `2.2.1` |
| `index.html` | About `2.2.1` |
| `public/js/modules/utils/index.js` | `utilsModule()` — storage, editHistory, 유틸 함수 |
| `public/js/modules/utils/object.js` | `clone`, `extend` |
| `public/js/modules/utils/string.js` | `capitalize`, `padZero` |
| `public/js/modules/utils/storage.js` | `storage` |
| `public/js/modules/utils/editHistory.js` | `editHistory` |
| `public/js/modules/utils/time.js` | 타임코드 유틸 |
| `public/js/caption.js` | `utilsModule()` import·호출부 전환 |

### Note

- `Fn.Format`, `Fn.Language`, `Fn.Encode*` 등은 utils가 아닌 **앱 설정·자막 포맷·인코딩 옵션** 영역 — `caption.js`에 유지, 추후 도메인별 모듈 분리
