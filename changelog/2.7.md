# 2.7.x

작업 목표 1 (모듈 분리): `caption.js` Shortkey 도메인을 `modules/shortkey/`로 분리.
작업 목표 3 (jQuery 제거): `jquery.shortcuts` 플러그인 → 바닐라 `shortcuts.js`.

---

## 2.7.0 — 2026-09-06

### Added

- `public/js/modules/shortkey/`
  - `index.js` — `shortkeyModule()` · `initialize({ ui, sheet, video, i18n })`
  - `shortcuts.js` — 바닐라 Shortcuts 엔진 (`event.code`)
  - `defaultKeys.js` / `customKeys.js` — 고정·커스텀 단축키
  - `convert.js` — 키 입력 → mask 문자열
  - `renderSettings.js` — 설정 UI (바닐라 DOM)
  - `init.js` — `init` · `registerKeys`
  - `targets.js` — `TEXT_TARGETS` · `TIME_TARGETS`

### Changed

- `caption.js` Shortkey 인라인 제거 → `shortkey.initialize` / `shortkey.init`
  - camelCase API: `defaultKeys` · `customKeys` · `convert` · `renderSettings` · `init` · `registerKeys`
  - 식별자 `Shortkey` → `shortkey`
  - `data-action="shortkey.renderSettings"`
  - 재할당되는 `sheet.current`는 핸들러에서 `sheet.current`로 접근
- Shortcuts 엔진
  - 키 매칭: `which`/`keyCode` → `event.code` (UA minus/plus 분기 제거)
  - API: `code` · `callback` · `start` · `stop` · `add` · `remove` · `removeAll` · `search`
  - 옵션: `preventDefault` (구 `isPrevented`)
  - `normalizeMask` — 중복 검사·저장 시 소문자·공백 정규화
- `init` / `registerKeys` 분리 — 커스텀 키 저장 시 `removeAll` + `registerKeys` + `renderSettings`만 재실행
- 설정 UI: `ui.applyI18n` · `querySelector` · cancel을 `button`으로 통일
- 편집 진입 가드: `.ui-dialog.on` → `.dialog.on`
- 핸들러 `return false` 제거 (엔진이 반환값을 사용하지 않음)
- `caption.js`는 부트스트랩 · ready만 유지

### Removed

- `public/js/plugin/jquery.shortcuts.js`
- `public/js/plugin/jquery.shortcuts.back.js`
- `public/js/plugin/shortcut.js`
- `index.html`의 shortcuts 스크립트 태그
- 빈 `public/js/plugin/` 디렉터리
