# 2.5.x

README 1단계: `caption.js` Sheet 도메인을 `modules/sheet/`로 분리.

---

## 2.5.0 — 2026-09-05

### Changed

- `caption.js` Sheet 도메인을 `public/js/modules/sheet/`로 분리
  - `sheetModule()` · `initialize({ i18n, header, ui, subtitle })`로 API 주입
  - 공개 진입점은 default `sheetModule`만 (`index.js`)
- 시트 상태·API camelCase 통일 (video/subtitle와 동일)
  - document: `language` · `format` · `timelines`
  - selection: `current` · `active` · `selectedRows` · `searchHits` · `focus` · `shift`
  - layout: `height` · `rowInfo` · `errorRows` · `canvas` · `scroll` · `offset` · `needsRedraw` · `cellStyle`
  - `lastIndex` · `canvas.bufferHeight` getter (`timelines.length - 1` · `height * 3`)
- 행위 API
  - `set` · `init` · `stateUpdate` · `convert` · `render` · `trigger` · `move` · `edit`
  - `command` · `update` · `updateTarget` · `insert` · `remove`
  - `undo` / `redo` · `search` · `rowOffset` / `timeSearch` · `multiple` · `config` · `autoSave`
  - `setCellStyle({ fontSize })`
- `Ev` 이벤트 이름 객체 제거 · 패널/툴바/스크롤/리사이즈는 `init/`에서 바인딩
- 빈 행은 `clone(EMPTY_TIMELINE)`만 사용 (템플릿 참조 공유 제거)
- `arrayHeight` 제거 — `rowInfo[i].height` SSOT · 오프셋 스캔은 `findRowAfterOffset`
- subtitle converter DTO `{ format, timelines }` (`sheet.set` · import/export)
- 전역/주입 식별자 `Sheet` → `sheet` (video · subtitle · caption)
- DOM 핸들: `root` · `head` · `headPanel` · `body` · `bodyScroll` · `panel`
- `jquery.scrollbar` 제거 — `#sheet` > `.sheet-head` + `.sheet-body`
  - `.sheet-body` > `.sheet-body-scroll` > `.sheet-trigger` + `.sheet-panel`
  - body 가로 스크롤 시 `headPanel`에 `translateX(-scrollLeft)`
- 시트 행 레이아웃 `table-cell` → **flex** + `box-sizing: border-box`
  - `layout/columns.js` — 열 너비 · left · memo gutter SSOT (`COL_RATE` · `MOVE_LEFT`)
  - 열 너비 `ceil(fontSize * rate)` → CSS 변수 `--sheet-col-*` / `move.left` / `getColWidth`
  - `cellStyle` — `fontSize` · `lineHeight`(`×1.65`) · `padding`(`/4.5`)
- edit UI 바닐라화
  - `colorPicker.js` (`createColorPicker`) · `rangeSlider.js` (`mountRangeSlider`)
  - `#time-editor` · 색상 팔레트는 jQuery UI / `plugin/colorpicker.js` 미사용
- 렌더 호출 순서 통일: `convert()` → `needsRedraw = true` → `render()`
- 히스토리 엔트리 `{ command, id, after, before, current }` · `command`: `insert`/`remove`/`update`/`multi.*`

### Removed

- `public/js/plugin/jquery.scrollbar.js` · `jquery.scrollbar.back.js`
- `public/js/plugin/colorpicker.js`
- `public/js/plugin/calc.js` · `smooth-scroll.js` (미로드 레거시)
- `public/css/jquery.scrollbar.css` · `colorpicker.css` (스타일은 `common.css`에 유지)

### Note

- GA `category: 'Sheet'` 문자열은 분석 연속성을 위해 유지
- `document.execCommand` deprecated — 유지·후순위(Selection/Range 교체)
- 단축키 레퍼런스 유지: `jquery.shortcuts.js`(사용) · `jquery.shortcuts.back.js` · `shortcut.js`
- jQuery 이벤트 네임스페이스·단축키 바닐라 전환은 후속 작업
