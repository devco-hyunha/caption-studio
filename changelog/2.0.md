# 2.0.x

GitHub 리팩터링 기준선 및 레거시 정리.

---

## 2.0.0 — 2026-08-28

### Added

- 운영 레거시 코드를 GitHub 리팩터링 기준선으로 추가
- SemVer, [VERSION](../VERSION), CHANGELOG 도입
- About UI 버전 **2.0.0** (`VERSION`, Git tag `v2.0.0`과 동일)

### Note

- **1.9.8** — Git 이전 운영 레거시 최종 번호 ([CHANGELOG Legacy](../CHANGELOG.md#legacy))
- **2.0.0** — Git 저장소·SemVer·About UI가 시작하는 버전
- 2021년 레거시 공지 팝업은 기준선에 포함하지 않음
- 호출되지 않던 `respond.min.js`, `html5-audio/`(WaveSurfer)는 기준선에 포함하지 않음
