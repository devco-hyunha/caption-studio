# 2.6.x

작업 목표 1 (모듈 분리): `caption.js` Interface(UI 셸) 도메인을 `modules/ui/`로 분리.

---

## 2.6.0 — 2026-09-06

### Changed

- `caption.js` Interface · Toast를 `public/js/modules/ui/`로 분리
  - `uiModule()` · `initialize({ i18n, getSheet, getActionContext })`로 API 주입
  - 공개 식별자 `Interface` → `ui` (sheet · video · subtitle · caption)
- UI API camelCase 통일 · ready 시 `ui.init()` 1회 바인딩
  - DOM: `wrap` · `layout` · `layer` · `anotherInput`
  - feedback: `alert` · `success` · `confirm`
  - dialog(공개): `dialog.open` / `dialog.close` · `switchFocus`
  - select(공개): `ui.select({ key, value })`
  - confirm 옵션: `successLabel` / `cancelLabel` (버튼 문구)
  - `applyI18n`
  - `tab` · `inputFile` · `dialog.init` · `select.init`은 `ui.init()` 내부 전용
- ui 모듈 jQuery 제거 (바닐라 DOM · `bindEvent`)
  - `toast.js` — 단일 `show({ type, message, title, options })`
  - `feedback.js` — alert / success / confirm
  - `dialog.js` — dialog · switchFocus
  - `widgets.js` — tab · select · inputFile · toggle
  - `applyI18n.js` — DOM i18n · select trigger 문구 동기화
- `wrap` / `layout`을 `querySelector`로 보관 (caption Shortkey·nav도 네이티브 호출)

### Fixed

- confirm `content`에 i18n `<br />`가 보이도록 `innerHTML` 적용 (title은 `textContent` 유지)

### Docs

- README: 레거시 구조(기준선)와 현재 구조를 분리, 작업 목표 상태·scope를 모듈에 맞춤
- changelog 2.1–2.6 헤더:「README 1단계」→「작업 목표 1 (모듈 분리)」

### Note

- `Shortkey` · `Fn.Format` / `Fn.Language`는 caption.js에 유지 (후속 분리)
- caption 잔여 jQuery(단축키·ready 일부)는 후속 작업
