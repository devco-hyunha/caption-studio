# 2.9.0-dev.3 — Shortkey 엔진 · 시트 이동·에딧 키 이관

브랜치: `feat/edit-shortkey` (베이스 `feature/tanstack-start`) — `/edit` 시트 키보드 진입을 shortkey로 이관.

`VERSION` / tag는 **React 완전 변환 완료 시** `2.9.0`으로만 반영한다.

### Decision

| 게이트 | 채택 | 대안 | 이유 / 기각 | 상태 |
|--------|------|------|-------------|------|
| 엔진 | `public/js` shortkey 포팅 (`shortcuts`) | hotkeys-js 등 | parity·YAGNI | 기본채택 |
| 키 소유 | shortkey만 전역 키 | widget `window` keydown 유지 | `defaultKeys` | 잠김 |
| 시트 포커스·에딧 모델 | `modeRef === 'edit'`로 키 분기. 시트 셀 contenteditable만으로 전역 키 막지 않음 | DOM 포커스면 전역 키 무시 | `!edit.state` · IME 중 React `mode` 지연 대비 `isEditing()` | 잠김 |
| 진짜 input | `checkIsInput` = text류 `input` / `textarea`만 | 모든 포커스 가능 요소 동일 무시 | 탭 rename·설정 input과 시트 셀 분리 | 잠김 |
| 키 mask 상태 | Zustand `useShortkeyStore` 기본 mask + 변경 시 재등록 | 코드 하드코딩만 / 커스텀 UI까지 | 데이터 틀 선배치. 설정 UI는 후속 | 잠김 |
| 커스텀 키 UI | 이번 작업 제외 | 이번 작업에 포함 | YAGNI | 기본채택 |

### Added

- `features/shortkey` — 엔진 `shortcuts` (mask/hold/down/`checkIsInput`/start/stop/add) + Vitest
- `bind-sheet-keys` — Tab/Shift+Tab, ←↑→↓, PageUp/Down, F2/Esc/Enter, printable→edit callback
- `default-sheet-key-masks` / `useShortkeyStore` — 기본 mask · `setMask` · masks 변경 시 `removeAll`+재등록
- `useSheetShortkey` — `/edit` 시트 수명주기, 시트 동작 API 주입
- `use-sheet-move` / `use-sheet-cell-edit` — 전역 keydown 제거, 이동·에딧 API만 노출

### Changed

- `sheet-body` — shortkey에 시트 액션 주입 (feature→widget import 없음)
- IME 편집 중 Tab — `isEditing()`으로 endEdit · composing/229 네비게이션 무시 · 지연 `setMode('edit')` 무효화

### Notes

- Shift+Arrow multi-select · Tab 끝행 insert · Ctrl+Z/Y · 검색 · video · 포맷/clip 키 · 커스텀 키 설정 UI는 미포함 (후속)
- `public/**` 미수정

### Verify

- `/edit` focus: Tab/화살표/Page 이동 (`/` parity)
- edit 중 화살표 이동 없음 · Esc 종료 · F2/Enter 진입
- 한글 IME 입력 후 Tab — 에디터 종료 + 다음 행 text 선택 (한 칸)
- 시트 contenteditable 포커스만으로 이동 키 차단 없음
- 탭명 rename `input` 포커스 시 시트 단축키 미동작
- widget에 `window` keydown 없음
- `pnpm test:run` — shortkey 엔진·store · `sheet-move` 통과
