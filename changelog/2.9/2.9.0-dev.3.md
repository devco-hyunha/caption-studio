# 2.9.0-dev.3 — Shortkey 엔진 · 시트 키 이관 (S2)

브랜치: `feat/edit-shortkey` — 바닐라 `public/js` shortkey 엔진을 `shared`에 포팅, `features/shortkey` 스토어(영속·legacy 승격) 신설, 시트 **이동·에딧·선택·CRUD 키**를 엔진으로 이관하고 widget `window` keydown을 제거한다.

`VERSION` / tag는 **React 완전 변환 완료 시** `2.9.0`으로만 반영한다.

### Decision

- **키 소유는 shortkey 엔진만** — widget `window` keydown 제거 (dev.2의 S1 임시 키 경로 종료). `defaultKeys`·커스텀 mask가 단일 정본
- **엔진은 도메인 무관 `shared/lib/shortcuts`**: `createShortcuts`(document capture keydown/keyup) · `createCodeMap`(mask token → `event.code`) · `mask`(normalize·key) · `checkIsInput`. React·스토어 의존 없음
- `checkIsInput`는 `input`/`textarea`/`select`/`option`만 입력으로 본다 — 시트 `contenteditable`은 **제외** (Decision). I/O 패널 `<select>` 포커스 중 ↑↓가 시트로 새는 것 방지
- **스토어**: `useShortkeyStore` 별도 create — `sheet` 스토어에 키 상태 뭉치기 금지 (README 스토어 원칙). `persist` + `partialize`로 **default와 다른 mask만** 영속
- **legacy 승격**: `/`의 `customkey-<storageId>`(`sheet-insert`/`sheet-remove`) → `shortkeyMasks` mask 맵. 병합 순서 default → legacy 승격 → 저장 masks
- **역참조 금지**: 위젯 → feature 방향만. `useSheetShortkey({ getActions })`로 시트 동작 API를 주입하고, feature는 widget을 import하지 않는다
- **키 등록은 기능별 registrar 조합**: `move-keys` · `edit-keys` · `selection-keys` · `mutate-keys` + printable callback. `defineSheetKey`가 mask 조회·IME 가드·`type: 'hold'`를 일괄 적용
- Space: 선택 토글 키가 **선점** — printable 타입 투 리플레이스에서 Space 제외 (`/` parity)

### Notes

- 엔진은 `document` **capture** 단계 keydown/keyup — `event.repeat` 홀드 throttle(`MOVE_REPEAT_INTERVAL_MS` 30ms)은 `use-sheet-move`이 유지
- IME 조합 중 keydown(`isComposing`·`keyCode 229`·`key 'Process'`)은 네비게이션에서 무시 — Tab 확정 시 이중 이동 방지
- `useSheetShortkey`는 masks 변경 시 `removeAll` + 재등록 (스토어 subscribe). `getActions`는 ref로 최신화
- Enter: 에딧 중이면 줄바꿈, 비에딧 text 열이면 진입. F2는 다중 선택 중 no-op. Esc은 다중 선택 토글 off, 에딧 중 값 취소·focus 유지
- Ctrl+Shift+A/D는 다중 선택 중·포커스 없음 시 no-op (S1 toolbar 동작과 동일 가드)
