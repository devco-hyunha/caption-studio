# 2.9.0-dev.8 — Video Sync · Video Player · Video Shortkey

브랜치: `feat/edit-video-sync` — `/edit`에 **react-player** 기반 `VideoPlayer`를 얹고, **시트 ↔ 플레이어 시간 싱크**(분 슬롯 인덱스)와 **video shortkey**(Ctrl+Space·Ctrl+←/→·Ctrl+↑/↓·Ctrl+Q·Alt+Q·Ctrl+`·Ctrl+Alt+←/→)를 연결한다. (`/` `sheet.seek.timeSearch`·`selecttime`·`move-prev/next` parity)

`VERSION` / tag는 **React 완전 변환 완료 시** `2.9.0`으로만 반영한다.

### Decision

- **제어 API 브리지** — 플레이어 제어는 `registerVideoPlayerControlApi`(마운트 1회 등록·언마운트 null) 단일 게이트. 시트·shortkey는 `getVideoPlayerControlApi()`로만 접근. video widget 전용 keydown 없음(키보드 진입 = shortkey 엔진)
- **시간 슬롯 인덱스** — `[start,end)`가 걸치는 **분(minute) 버킷** `TimeSlotIndex`(Map)으로 `timeSearchAll`·이전/다음 start 이웃 탐색을 O(버킷)로 수행. 세션용·비영속. 탭 전환·import·insert/remove·undo/redo·셀 시간 편집 시 슬롯 갱신
- **싱크 스토어 분리** — `useVideoSyncStore`(timeSlots·activeIndices)는 `useSheetStore`와 분리. 시트 데이터 변경 지점(selection/time/undo/sheets)에서 video-sync 액션을 호출하는 단방향 의존
- **다중 cue** — `timeSearchAll`이 겹침 행을 오름차순 indices로 반환 → 오버레이 줄바꿈 결합·시트 행 highlight·Prev=min start / Next=max start 기준
- **입력 탭** — File / URL만. YouTube·Vimeo는 URL 정규식 자동 감지. Enter 시 `blur()` → 전역 shortkey 즉시 동작
- **타입 분리** — `VideoPlayerProps`·`VideoControlsProps`·`VideoPlayerHandle`·`VideoSyncStore`·`TimeSearchHit`·`TimeSlotIndex` 등 인라인 타입을 slice `types.ts`로 이동

### Changed

- `formatTimecode` → `formatTime(ms, slim?)` — `slim` true는 플레이어 표시(`M:SS`/`H:MM:SS`), false(기본)는 `HH:MM:SS,mmm`. export·sheet row 사용처 갱신
- `asHtmlString` — `sheet/lib/sheets` local → `shared/lib/utils`로 승격(중복 제거)
- `EMPTY_TIMELINES` — `sheet-body` local const → `entities/subtitle-sheet` export로 공통화
- `CHROMELESS_PLAYER_STYLE` 제거 — ReactPlayer `className="h-full w-full [--controls:none]"`로 이동. `CHROMELESS_PLAYER_CONFIG`(iframe 파라미터)만 유지

### Fixed

- **URL Enter 후 전역 shortkey** — URL 입력 Enter 시 `blur()` → `Ctrl+Space`가 즉시 재생 동작(인풋에 공백 삽입 방지)
- **재생 불가 소스 재Load** — 동일 URL 재Load 시 `handleLoad` early-return → `"재생할 수 없는 소스입니다."` 유지(동일 상태서 에러 소실 방지)

### Notes

- 시트 ↔ 플레이어는 `syncPlaybackFromPlayerTime`(player time → activeIndices)로 단방향. 동일 indices면 no-op(루프·리렌더 방지)
- Prev/Next 기준: 출력 자막 있으면 min/max start, 없으면 플레이어 현재 시각. 분 슬롯 버킷을 안/밖으로 확장해 탐색
- `timeSearchAll` 겹침 다중 cue → 오버레이 `<br />` 결합, 시트 행 `bg-sky-50` + inset highlight
- Excel·JSON export는 dev.7 유지. video는 세션 전용(영속 없음)
