# 2.9.0-dev.8 — Video ↔ Sheet sync

브랜치: `feat/edit-video-sync` (베이스 `feature/tanstack-start`) — `/edit` react-player · 분 슬롯 · 다중 cue 싱크 · shortkey video.

`VERSION` / tag는 **React 완전 변환 완료 시** `2.9.0`으로만 반영한다.

### Decision

| 게이트 | 채택 | 대안 | 이유 / 기각 | 상태 |
|--------|------|------|-------------|------|
| 플레이어 코어 | pnpm `react-player` | Video.js / native `<video>`만 | 가벼움 · React props · YT/Vimeo 기본. Video.js는 커스텀 UI 전제에서 이점 적고 번들 큼 | 잠김 |
| 컨트롤 UI | widget 밖 커스텀 UI | Video.js control bar DOM 삽입 | bar 해킹 폐기 | 잠김 |
| 소스 범위 | File · URL(직접/YT/Vimeo 자동 감지) | YT·Vimeo 전용 탭 유지 | URL 한 칸으로 충분 | 잠김 |
| 동기 방향 | 단방향 + 명시 seek (`timeupdate`→시트, Ctrl+Q/Prev·Next→`seekTo`) | 양방향 자동 동기 · 행 클릭 seek | 루프 방지 · `/` parity(행 클릭=포커스만) | 잠김 |
| 키 | shortkey 핸들러 (play · ±10s · volume · videoJump · sheetJump) | video widget 전용 keydown | 키보드 진입=shortkey | 잠김 |
| 오버레이·로드 UI | Verify용 최소 (Load · 텍스트 · Prev/Next) | `/` 풀 video-import 셸 | 풀 셸은 S6 | 잠김 |
| 활성 자막 | 다중 `indices[]` (`timeSearchAll`) | `/` 첫 행만 | 겹침 라인 개선 | 잠김 |
| 시간→행 인덱스 | 분 슬롯 + 전체 rebuild · 행 단위 sync/insert/remove | 매 틱 전수 / TextTrack | 후보 축소 · mutate와 同行 | 잠김 |
| Prev/Next | 출력 cue start 이웃 · 분 슬롯 순회 (없으면 재생 시각) | 행 index ±1 | 겹침 시 index 꼬임 방지 | 잠김 |
| 슬롯 스토어 | `features/video-sync` · `useVideoSyncStore` (비영속) | `sheet-session`에 합침 | 검색·히스토리와 분리 | 잠김 |
| 비디오 영속 | 이번에 미도입 (로컬 파일·URL 모두) | IndexedDB / File System Access / URL만 persist | 로컬 파일 유지 비용·제약 · 사용자 패스 | 잠김 |

### Added

- `entities/subtitle-sheet` — `timeSearch` · `timeSearchAll` · 분 슬롯 인덱스 · start 이웃 탐색 · Vitest
- `features/video-sync` — `useVideoSyncStore` (timeSlots · activeIndices) · mutate↔슬롯 · playback sync · seek/prev/next · play/volume 브릿지
- `widgets/video-player` — react-player · File/URL 로드 · chromeless · 커스텀 컨트롤 · 오버레이 · Prev/Next
- shortkey — Ctrl+Q videoJump · Alt+Q sheetJump · Ctrl+Space · Ctrl+←/→ · Ctrl+↑/↓
- 의존성 — `react-player` (Video.js / `@types/video.js` 제거)

### Changed

- `/edit` — 플레이어 + 시트 레이아웃
- `sheet-body` / `sheet-row` — 재생 활성 행 하이라이트 · mutate 후 슬롯·activeIndices 갱신
- `apply-sheet-format` — 포맷 전환 후 `rebuildVideoTimeSlotsFromActiveSheet`
- `VideoControls` — `currentTime` 내부 보유 (`timeupdate` 시 플레이어 전체 리렌더 방지)
- 로드맵 S5 · `work-feat-edit-video-sync`

### Notes

- 행 클릭은 포커스만 · 영상 seek는 Ctrl+Q / overlay Prev·Next
- seek 성공 시에만 동기화 · 활성 indices는 `timeSearchAll` 다중 유지 (단일 행으로 덮지 않음)
- 비디오 소스·재생 위치 localStorage 영속 없음 (패스)
- `public/**` 미수정 · 시트/video widget `window` keydown 없음
- sheet-session 스토어 분리 → `feat/edit-sheet-session-split` (별도)

### Verify

- file · URL · YouTube · Vimeo 로드 후 재생·일시정지·seek → 시트 하이라이트·오버레이
- 겹치는 자막 → 시트·오버레이에 여러 행
- Ctrl+Q → 현재 행 start seek · Alt+Q → 재생 행으로 시트 이동
- Ctrl+Space · Ctrl+←/→ · Ctrl+↑/↓ · overlay Prev/Next
- SMI↔SRT 전환 후 싱크 유지
- 재생 중 플레이어 영역 전체가 `timeupdate`마다 깜빡이지 않음 (컨트롤 시간만 갱신)
