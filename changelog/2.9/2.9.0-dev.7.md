# 2.9.0-dev.7 — Subtitle I/O (SMI/SRT/VTT/JSON/Excel)

브랜치: `feat/edit-subtitle-io` (베이스 `feature/tanstack-start`) — `/edit` 자막 가져오기·내보내기 · 시트 형식 변환.

`VERSION` / tag는 **React 완전 변환 완료 시** `2.9.0`으로만 반영한다.

### Decision

| 게이트 | 채택 | 대안 | 이유 / 기각 | 상태 |
|--------|------|------|-------------|------|
| 파서 위치 | `entities/subtitle` 순수 · UI/핸들러는 `features/subtitle-io` | 전부 feature / shared에 파서 | FSD · 도메인 vs 인터랙션 분리 | 잠김 |
| 인코딩 경로 | 클라이언트 only (`iconv-lite` + vite buffer 폴리필) | 서버 API 신설 / UTF-8만 | `/` 다중 인코딩 · EUC-KR SMI | 잠김 |
| 포맷 범위 | SMI/SRT/VTT/JSON/Excel — **이 브랜치** | Remaining·S6로 분리 | I/O 도메인 = 현재 브랜치 | 잠김 |
| import 포맷 | SMI/SRT 파일만 | VTT/JSON/Excel import 포함 | `/` importHandlers와 동등 | 잠김 |
| export 인코딩 UI | **SMI만** 선택 (기본 EUC-KR) · SRT/VTT/JSON/Excel은 UTF-8 고정 | 전 포맷 인코딩 셀렉트 | SMI 외 다중 인코딩 비용·실사용 | 잠김 |
| JSON/Excel 탭 | 자막 탭 전체 → JSON `{ sheets }` · xlsx 워크시트 복수 | 활성 탭만 | 탭 모델에 맞춘 I/O | 잠김 |
| import 후 시트 | 활성 탭 timelines 교체 (`setActiveTimelines`) | 항상 새 탭 | `/` import | 잠김 |
| import/export UI | Verify용 최소 패널 · 풀 모달/셸은 S6 | 풀 UI를 이번 작업에 포함 | 수동 Verify. 풀 셸은 S6 | 잠김 |
| 시트 형식 버튼 | SMI/SRT 전환 시 **전 탭** timelines 변환 | UI 열만 변경 / 활성 탭만 | `converters` 연결 | 잠김 |

### Added

- `entities/subtitle` — SMI/SRT parse·serialize · VTT/JSON serialize · Excel(zip STORE) · encoding · convert · Vitest
- `features/subtitle-io` — import FileReader · export encode/download · `convertSheetTimelines` · Verify `SubtitleIoPanel`
- `setActiveTimelines` — import 시 활성 탭 교체
- `applySheetFormatChange` — `/edit` SMI/SRT 버튼 → 전 탭 변환
- vite — `buffer` / `string_decoder` alias (iconv-lite 브라우저)

### Changed

- `sheet-body` — I/O 패널 연결 · `workbookTabs` (json/excel용)
- `/edit` — 형식 버튼이 timelines 변환 후 UI format 갱신
- 로드맵 S4 · Remaining — Excel/VTT/JSON을 S4 I/O 범위로 정리

### Notes

- 가져오기: SMI/SRT만. VTT/JSON/Excel은 내보내기
- JSON: `{ sheets: [{ name, timelines }, ...] }` · Excel: 탭 이름 = 워크시트 이름
- 풀 import/export 모달 · i18n 셸 → S6
- `public/**` 미수정 · 시트 widget `window` keydown 없음

### Verify

- SMI/SRT 가져오기 → 시트 행·시간·텍스트 · 한글/특수문자
- SMI/SRT/VTT/JSON/Excel 내보내기 · SMI↔SRT round-trip
- JSON/Excel — 자막 탭 수만큼 sheets/워크시트
- SMI 내보내기 인코딩 선택 · SRT/VTT 스타일 제거 · UTF-16 BOM SMI 가져오기
- `/edit` SMI/SRT 버튼 — 전 탭 열·데이터 변환
- `pnpm test:run` — encoding · import · export · parse/serialize · convert · excel
- `pnpm lint` 통과
