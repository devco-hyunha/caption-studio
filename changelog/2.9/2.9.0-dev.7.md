# 2.9.0-dev.7 — Subtitle I/O (가져오기·내보내기)

브랜치: `feat/edit-subtitle-io` — `/edit` React 시트에 **SMI/SRT/VTT/JSON/Excel** parse·serialize + **가져오기·내보내기** 핸들러/최소 UI + 시트 timelines 연결을 이관한다. (`/` `subtitle/convert/*`·`importHandlers.js`·`export/*`·`encode.js`·`valid.js` parity)

`VERSION` / tag는 **React 완전 변환 완료 시** `2.9.0`으로만 반영한다.

### Decision

- **파서 위치** — `entities/subtitle` 순수(parse·serialize·encoding·html 정규화) · UI/핸들러는 `features/subtitle-io`. FSD 도메인 vs 인터랙션 분리
- **인코딩 경로** — 클라이언트 only. `iconv-lite` npm 의존성(EUC-KR·big5 등 parity). `buffer`는 Vite `resolve.alias: { buffer: 'buffer/' }`로 매핑 — `globalThis.Buffer` 몽키패치 불필요(`safer-buffer`/`safe-buffer`/`string_decoder`가 alias로 npm `buffer`를 해석)
- **포맷 범위** — SMI/SRT/VTT/JSON/Excel(zip) **이 브랜치**. Remaining·S6로 분리하지 않음
- **import/export UI** — Verify용 최소 진입점(`SubtitleIoPanel`). 풀 모달·i18n 셸은 S6
- **import 후 시트** — 활성 탭 timelines 통째 교체(`setActiveTimelines`). `/` parity
- **import 인코딩 UX** — UI 선택 + `FileReader.readAsText`(BOM은 브라우저 우선). import/export 인코딩 **각각** 선택(SMI 내보내기 기본 EUC-KR)
- **encodeHtml 정본화** — `entities/subtitle`의 `encodeHtml(input, { clone, colorMode })`가 정본. `colorMode: 'font'`(SMI 파싱 color→`<font color>`) / `'keep'`(셀 저장 color 속성 보존). widget `encodeCellHtml`은 `{ clone: true, colorMode: 'keep' }` 위임
- **타입 분리** — 모든 인라인 타입(`EncodeHtmlOptions`·`BuiltExportFile`·`SubtitleIoPanelProps` 등)을 slice `types.ts`로 이동

### Changed

- **병합·재사용 리팩터링** (동작 유지, 중복 제거):
 - `encodeCellHtml` → `encodeHtml` 정본 위임. color 분기를 `colorMode` 옵션으로. `valid.ts`가 원본 `validCellHtml`과 치환 규칙 완전 일치
 - snapshot alias(`cloneTimelineSnapshot`·`emptyTimelineSnapshot`) 제거 → `cloneTimeline`·`createEmptyTimeline` 직접 import. `sheet-history` Public API 축소
 - `removeActiveTimelineAt` + `removeActiveTimelineAtForHistory` → `clearSelection: boolean` param 통합
 - `getActiveSheet`·`patchActiveSheetKeep` 헬퍼 추출 — 11개 함수 boilerplate 수렴
 - `convert-sheet-timelines`의 `toSheetTimelineItem` → `cloneTimeline` 재사용(`sync` 필드 추가 복사)
 - `readFileBytes`(미사용) 제거, `readFileText` 단일화
- 타입 분리 — `entities/subtitle/types.ts`·`features/subtitle-io/types.ts`·`sheet-history/types.ts`에 인라인 타입 이동
