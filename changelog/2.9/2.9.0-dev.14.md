# 2.9.0-dev.14 — L3 shortkey 엔진 meta 지원 · dual registration

브랜치: `feat/shortkey-l3-meta` — `52e9791` 통합선 머지. 상세 [docs/roadmap/l3-macos-cmd.md](../../docs/roadmap/l3-macos-cmd.md). 커스텀 ctrl 키의 Cmd 병행 등록, 엔진 mask 파서에 meta 토큰을 넣는다.

`VERSION` / tag는 **React 완전 변환 완료 시** `2.9.0`으로만 반영한다.

### Decision

- **엔진 meta 토큰 (채택) vs 외부 hotkeys 라이브러리 (기각)** — `create-shortcuts` `run()`이 `metaKey` 읽음, mask 파서·`getKey`에 `meta` 참여. YAGNI — 자체 엔진 확장.
- **dual `ctrl+*,meta+*` comma 병행 (채택) vs OS 감지 분기 (기각)** — OS 감지·SSR 의존 없음. `REDO` comma 선례.
- **고정키 B/I/U·클립·undo dual 미적용 (채택)** — 고정키는 설정 변경 불가, 에딧 중 네이티브 양보 설계. 승인 범위는 커스텀 ctrl 키의 Cmd 병행.

### Changed

- `MaskObject`에 `meta?: boolean` · mask 파서·`getKey` meta 참여
- `DEFAULT_SHEET_SHORTKEY_MASKS` 커스텀 ctrl 키 dual 등록(insert/remove·time±·search·carve·videoJump·play·seek±·volume±·cue±). `alt+q`(sheetJump)는 dual 대상 아님
- `META_*` mask 상수 신규

### Added

- Vitest: `meta+b` 매칭 · dual 등록 · ctrl 경로 불변 · 스토어 dual mask
