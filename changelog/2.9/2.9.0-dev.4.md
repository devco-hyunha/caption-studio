# 2.9.0-dev.4 — 시트 clip · time ±jump · SMI dur/error parity

브랜치: `feat/edit-sheet-time` — shortkey에 **clip(BIU·clear·X/C/V)** · **time ±jump(Ctrl+Plus/Minus)** 를 이관하고, 행 뷰를 `/` SMI/SRT **dur·error** parity에 맞춘다. (선행 `feat(shortkey): sheet clip keys…` · `fix(sheet): 렌더 중 ref·impure 접근 제거` 포함)

`VERSION` / tag는 **React 완전 변환 완료 시** `2.9.0`으로만 반영한다.

### Decision

- **clip / time도 shortkey 엔진만** — widget `window` keydown 추가 금지. registrar는 `clip-keys` · `time-keys`로 분리 (`bind-sheet-keys` 조합)
- **동작 API는 widget 훅** — `useSheetClipActions` · `useSheetTimeActions`. feature는 `getActions` 주입만 (역참조 금지)
- **서식(BIU)**: 에딧 중 → 에디터 `execCommand`. 다중 선택 → 선택 행 `text` 일괄 (`/` multiClip). 단건 → text/memo 셀만 스토어 갱신
- **clear / cut / copy / paste**: 비에딧·비다중·text 타깃만. 에딧 중은 네이티브에 양보
- **time ±jump**: 다중 선택 → 선택 행 start/end **둘 다** ±step (`/` multiClip parity). 단건 → 포커스 time 열(starttime/endtime)만. step는 localStorage `jump_val`(JSON.parse → parseInt, 기본 30ms) — `/`와 하이브리드 공유
- **SMI 행 뷰**: end/dur는 **다음 행 start − start** (`/` renderRowsHtml). 마지막 행 dur 빈값. error는 `start > nextStart`
- **SRT 행 뷰**: storedEnd 우선. error는 `end > nextStart` · `end < start`
- 타임라인 ms patch는 **entities 순수 함수 + 스토어 액션** (`replaceTimelineAt` · `replaceTimelinePatches`). widget은 조립만

### Notes

- 에딧 중 BIU는 selection 유지한 채 `execCommand`. clear/클립은 에딧·다중 중 no-op
- time minus: 단건은 값이 0이면 변화 없음. 다중은 start/end를 `max(0, …)`로 clamp
- `jump_val` corrupt·빈값·비숫자는 기본 30ms
- SMI 표시 end는 다음 행 start로 **파생** — 스토어 `timeline.end`를 덮어쓰지 않음. nudge는 stored start/end만 변경
