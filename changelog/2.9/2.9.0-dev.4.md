# 2.9.0-dev.4 — Sheet 행 다중 선택 · CRUD · shortkey 연결

브랜치: `feat/edit-sheet-crud` (베이스 `feature/tanstack-start`) — `/edit` multi-select · 행 insert/delete · selection/format 키.

`VERSION` / tag는 **React 완전 변환 완료 시** `2.9.0`으로만 반영한다.

### Decision

| 게이트 | 채택 | 대안 | 이유 / 기각 | 상태 |
|--------|------|------|-------------|------|
| `selectedRows` 보관 | 런타임만 시트 스토어 필드 (`multipleActive`/`multipleStart` 포함, 영속 제외) | 별도 selection 스토어 / 영속 포함 | 영속 제외는 잠긴 결정. 스토어 신설 YAGNI | 기본채택 |
| insert/delete API | `entities/subtitle-sheet` 순수 함수 + 스토어 액션 | widget 안에 mutate | FSD · 도메인 위치 | 기본채택 |
| 키 연결 | shortkey 핸들러만 추가 (엔진 재작성 없음) | 시트 `window` keydown 재도입 | 키보드 진입=shortkey (잠김) | 잠김 |
| Space 토글 | multiple 모드에서 현재 행 토글 | 이번 작업에서 Space 제외 | `/` parity | 잠김 |
| 툴바 셸 | 이후 셸 작업. 이번엔 Verify용 임시 버튼만 | 이번 작업에 최소 툴바까지 / API만 | 셸·i18n은 후속. 수동 Verify 진입점 필요 | 기본채택 |
| multiple 서식 | Bold/Italic/Underline (+ Ctrl+B/I/U) | 시간 ±·색까지 / 이번 작업 제외 | Verify·parity 최소. 시간·색은 후속 | 잠김 |

### Added

- `entities/subtitle-sheet` — selection 순수 함수 · insert/delete · `updateSelectedTexts` + Vitest
- 스토어 액션 — `toggleMultiple` · `toggleSelectedRow` · `setMultipleStart` · `insertTimelineAfter` · `removeTimelineAt`
- shortkey — Shift+↑/↓ · Space · Ctrl+Shift+A/D · Ctrl+B/I/U 마스크·핸들러
- `widgets/sheet` — `selectedRows` 하이라이트 · Tab 끝행 append→insert·포커스·스크롤 · Verify 임시 버튼 (다중선택/행추가·삭제/B·I·U)
- `apply-text-format` — 선택 행(또는 단건) text 서식 토글 + Vitest

### Changed

- multiple 중 — 셀 클릭/더블클릭/우클릭·F2/Enter/타이핑으로 에딧 진입 금지 (`/` bindPanel parity)
- Esc — multiple이면 모드 종료, 아니면 에딧 취소
- insert 후 포커스 — rows·`totalHeight` 커밋 뒤 적용 (스크롤 클램프 방지)
- `use-sheet-window` — rows 변경 시 `useLayoutEffect`로 윈도 커밋

### Notes

- 툴바 셸·i18n·시간 ±·색 multiClip · undo/검색 · subtitle I/O · video 키는 미포함
- `selectedRows` / multiple 상태는 디스크 제외 (`partialize` 유지)
- `public/**` 미수정

### Verify

- Shift+↑/↓ 범위 선택 · 행 하이라이트 (`#cef`) · Space 토글 · Esc로 multiple 종료
- multiple 중 에딧 진입 없음 · B/I/U 버튼·Ctrl+B/I/U로 선택 행 text 서식
- Tab 마지막 행 — insert 후 새 행 포커스 · 화면 하단이면 스크롤 따라감
- 행 추가/삭제 (버튼·Ctrl+Shift+A/D) · multiple 중 추가/삭제 비활성
- `selectedRows` 비영속 · widget에 `window` keydown 없음
- `pnpm test:run` — selection · insert/delete · text-format · shortkey 통과
