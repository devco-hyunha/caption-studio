# 2.9.0-dev.9 — Sheet Body 리팩터링 (sheet-body 슬림화 · action composite)

브랜치: `refactor/sheet-body` — `widgets/sheet`의 `sheet-body`를 **슬림화**하고, action wiring을 **composite 훅**으로 일원화, toolbar·행 렌더·재생 highlight를 **섹션/훅별 분리**한다. (`/` 기능 parity 유지, UX 변경 없음)

`VERSION` / tag는 **React 완전 변환 완료 시** `2.9.0`으로만 반영한다.

### Decision

- **action composite** — search·selection·clip·time·video·undo·move wiring 순서(selection → move → shortkey)를 `lib/actions/use-sheet-body-actions.ts`로 캡슐화. `sheet-body`는 cell-edit 결과·window 값·커밋·검색 게이트만 입력받는다.
- **import 조립 composite 이동** — `handleImported`(endEdit·setActiveTimelines·슬롯 rebuild·history reset·search clear·setScrollTop(0)·applyFocus row 0)를 composite로 이동. body는 composite가 반환한 콜백을 toolbar에 연결만.
- **stable wrapper 게이트** — `closeSearchPanel`·`isSearchInputFocused`를 `sheet-body`의 stable wrapper로 cell-edit·search-actions에 공유(순환 배선 방지, D9 유지).
- **toolbar 섹션 분리** — 상단 툴바를 `ui/sheet-body/toolbar/`(index·buttons·search·io)로 분리. timelines·workbookTabs는 툴바가 스토어에서 생성, 점프·import 콜백만 body가 소유.
- **scroll 셸 분리** — 스크롤 래퍼 + content 래퍼를 `ui/sheet-body/scroll-container.tsx` presentational로 분리. refs·scroll 이벤트는 body(useSheetWindow)가 소유.
- **행 렌더 셸 분리** — `sheet-panel-body` div + 윈도 indices 행 렌더를 `ui/sheet-body/sheet-body-rows.tsx` presentational로 분리. totalHeight·paddingTop CSS 변수, 행 높이·재생 highlight·검색 히트·셀 이벤트는 props 소비.
- **playbackSet 훅 분리** — activeIndices(store) → Set 변환을 `features/video-sync/lib/use-playback-set.ts`로 이동. body는 store 직접 구독 제거. Set 변환 단일 출처(오버레이는 activeIndices 배열 소비).
- **ISP props 번들** — 셀 이벤트는 `cellEvents`, 에디터 input 이벤트는 `inputEvents`, 에디터 좌표는 `rect`(`SheetCellRect`) 번들로 축소. toolbar는 `SheetBodyToolbarActions` 번들만 소비.
