# 2.9.0-dev.19 — 글자색 feature · toolbar 팔레트/피커 · color0~7/clear 단축키

브랜치: `feat/sheet-color` — `7e6e9b8` 통합선 머지. Remaining **작업 B** — `features/sheet-color` 슬라이스 · DialogShell 기반 color selector · 8셀 팔레트 영속(`CaptionColorTemp`) · color-reset · Ctrl+1..8 / Ctrl+9 커스텀 키 · i18n. Remaining color 계열 달성.

`VERSION` / tag는 **React 완전 변환 완료 시** `2.9.0`으로만 반영한다.

### Decision

- **color API 위치 `features/sheet-color` 신규 (채택) vs `widgets/sheet/lib`·clip 확장 (기각)** — 도메인 분리. clip에 color 뭉치기 금지. DOM exec는 widget wiring이 surface·history deps 주입.
- **contenteditable 접근 widget wiring → feature 인자 주입 (채택) vs feature가 sheet store/ref 직접 (기각)** — feature→widget 역참조 금지. `use-sheet-color-wiring`이 surface·다중·history 조립.
- **`useColorStore` `create()` 영속 분리 (채택) vs sheet/format store 확장 (기각)** — 팔레트는 포맷·언어와 무관 도메인.
- **피커 React 재작성 + `react-colorful` (채택) vs 바닐라 `colorPicker.js` 이식 (기각)** — HSB/`color-math` 순수 함수 Vitest. DOM drag는 React state.
- **color0~7·colorClear `CUSTOM_SHORTKEY_IDS` 확장 (채택) vs 고정키 (기각)** — `/` customKeys parity. 고정키 dual 금지 관례 유지.
- **`SheetColorCommand` shared 정본 (채택) vs slice alias (기각)** — shortkey·sheet-color all-direct (`shared/types/color-command.ts`).
