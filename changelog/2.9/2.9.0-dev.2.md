# 2.9.0-dev.2 — Sheet UI · 영속 스토어 · 셀 포커스 이동 · 다중 선택 + 행 CRUD

브랜치: `feat/edit-sheet` — `/edit` sheet UI(Legacy page 스냅), React Compiler, `subtitleSheets` 영속, 셀/행 포커스 이동, **S1 다중 선택(Space·Shift) + 행 추가/삭제**까지 한 단계로 기록.

`VERSION` / tag는 **React 완전 변환 완료 시** `2.9.0`으로만 반영한다.

### Decision

- Legacy / Virtual 비교 후 **Legacy(page 스냅 + paddingTop 흐름)** 채택, TanStack React Virtual 경로 제거
- Virtual은 page 스냅을 맞춰도 `useVirtualizer` scroll 구독으로 Body 리렌더가 잦음 — Legacy는 page 안 `setState`가 거의 없어 리렌더·memo 부담이 작음
- React Compiler는 Babel 대신 **Oxc 네이티브** (`compiler: true`) 사용
- S1 스토어: **기존 `useSheetStore` 확장** (다중 선택·행 CRUD). 별도 selection/CRUD store 선생성 없음 (`subtitleSheets` 동일 도메인)
- 다중 선택 상태 (`multipleActive` / `multipleStart` / `selectedRows`): **런타임 전용** — 영속 JSON에서 제외
- 행 insert/delete: **`entities` 순수 함수 + 스토어 액션**, widget은 조립만 (R5 — `sheet-body` 몰아넣기 금지)
- Space 키: 다중 선택 중 **현재 행 토글** (3001 기본 기능 parity). `' '` → 편집 진입 분기는 **제거**, Enter 진입 유지. 커스텀 키(ctrl+Space)·편집 중·다중 선택 밖은 no-op
- 키 진입: S1 구간은 **임시 widget `window` keydown** 유지 — shortkey 엔진 이관은 **S2**

### Notes

- Space는 `useSheetMove`가 처리(다중 선택 토글), 편집 진입은 Enter·더블클릭·우클릭·문자 키. `isPrintableKey`는 Space를 문자로 보지만 포커스 모드에서 에디터가 키를 선점하므로 편집이 열리지 않음
- 영속 JSON에서 `scroll` / `current` / `selectedRows` / `multipleActive` / `multipleStart` 제외 (뷰·선택 상태는 런타임)
- 행 추가/삭제 후 포커스는 **pending focus** — 새 행이 렌더에 반영된 뒤 `useLayoutEffect`가 적용 (아니면 `scrollHeight` 클램프)
- `use-sheet-cell-edit.ts`의 `react-hooks/exhaustive-deps` warning 1건 → hook 분리 후 **해결** (0 warning). window keydown effect는 `modeRef`/`targetRef` 가드 + `tryBeginEditFromKeyRef` deps, innerHTML effect는 `inputRef`/`modeRef` deps
- 포커스 hook의 `refineRafRef`는 `useRef(0)` truthy 체크 — raf id 0은 발생하지 않으므로 cancel 판정에 안전
- `SheetEditKeyProbe` — React `KeyboardEvent<HTMLDivElement>`와 window `KeyboardEvent` 모두 구조적으로 수용 (keydown probe 공유)
