# 2.9.0-dev.2 — Sheet UI · 영속 스토어 · 셀 포커스 이동

브랜치: `feature/tanstack-start` — `/edit` sheet UI(Legacy page 스냅), React Compiler, `subtitleSheets` 영속, 셀/행 포커스 이동까지 한 단계로 기록.

`VERSION` / tag는 **React 완전 변환 완료 시** `2.9.0`으로만 반영한다.

### Decision

- Legacy / Virtual 비교 후 **Legacy(page 스냅 + paddingTop 흐름)** 채택, TanStack React Virtual 경로 제거
- Virtual은 page 스냅을 맞춰도 `useVirtualizer` scroll 구독으로 Body 리렌더가 잦음 — Legacy는 page 안 `setState`가 거의 없어 리렌더·memo 부담이 작음
- React Compiler는 Babel 대신 **Oxc 네이티브** (`compiler: true`) 사용

### Added

- Sheet 윈도: `find-row-after-offset` / `sheet-render-range` (`getRenderRange`) / `use-sheet-window` (page = viewport×3 스냅)
- Sheet UI: `SheetBody` / `SheetRow` / `SheetCell` / `SheetCellEditor` / `SheetHeader` / `SheetPanel` / `SheetFooter` / `SheetTab` / `SheetTabMenu`
- `use-sheet-tab-rename` — 탭 rename 상태·검증·포커스
- `shared/ui` — `context-menu` / `dropdown-menu` / `input`
- `shared/lib/timecode` — `formatTimecode` / `parseTimecode`
- React Compiler — `oxc-transform-react` + `@vitejs/plugin-react` `compiler: true`
- `entities/subtitle-sheet` — `Sheet` / `SheetsState` / `SavedState`, `editable-column`, `tab-names`, CRUD·normalize (`subtitle-sheets`), Zustand `useSheetStore` + `storage` persist (키 `subtitleSheets`, `SUBTITLE_TEMP` 승격, **400ms debounce**)
- `sheet-move` / `use-sheet-move` — row/col/page 이동 + `scrollRowIntoView` / `scrollColIntoView` + Vitest

### Changed

- `/edit` Legacy/Virtual 토글 제거, `@tanstack/react-virtual` 의존성 제거
- `vite.config.ts` — `viteReact({ compiler: true })`
- `eslint.config.js` — `recommended` → `recommended-latest`
- `use-sheet-window` — render 중 ref 갱신 제거 (Compiler `refs` 규칙), `setScrollTop` 추가
- sheet UI 색상·격자: Tailwind `neutral` / `sky` / `red`, body 격자 `neutral-200/75`
- sheet footer: shadcn Button · 커서 앵커 탭 메뉴(이름 바꾸기/복사/삭제) · rename Input · 탭 가로 스크롤
- 탭별 scrollTop: 레거시 `persistActiveView` / `sheets[].scroll` 복원
- sheet-cell-editor: 최초 비활성 · 더블클릭/우클릭/문자 입력 활성화 · blur 저장
- `useSheets` — 스토어 thin adapter (`bodyScrollTopRef` + 탭 전환 scroll persist)
- `widgets/sheet` — 행/탭 뷰 매핑·UI만 유지, 도메인 타입·탭명·영속은 entity Public API
- `useSheetCellEdit` — `applyFocus` / `endEdit`
  - 세로·가로 뷰 밖이면 `scrollTop` / `scrollLeft` 맞춤
  - 키 반복 시 좌표·하이라이트 즉시 갱신 (실측은 최신 이동만 1프레임 보정)
  - sticky index 너비 inset (start 등이 index에 가려지지 않음)
- `SheetCell` / `SheetRow` — index `sticky left-0` + 행 선택/에러 배경
- `SheetPanel` — 헤더 index는 `translateX` 역보정으로 고정
- `columns.getColumnLeft` / `createColumnVars` — 레거시 `leftFor` 대응 · CSS 변수 주입
- 키 홀드 이동 — `event.repeat` 최소 간격은 `MOVE_REPEAT_INTERVAL_MS`(`use-sheet-move.ts`) 기준
