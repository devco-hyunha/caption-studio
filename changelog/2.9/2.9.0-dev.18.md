# 2.9.0-dev.18 — 편집 surface toolbar (자막편집 토글 · B/I/U)

브랜치: `feat/sheet-edit-toolbar` — `b590a07` 통합선 머지. Remaining **작업 A** — surface·서식 API·키는 이미 완료된 상태에서 toolbar 조립(토글·B/I/U)과 IME typing 시 surface ON 표시 지연 해소만 반영. color-reset·팔레트는 **dev.19**.

`VERSION` / tag는 **React 완전 변환 완료 시** `2.9.0`으로만 반영한다.

### Decision

- **버튼 위치 `SheetBodyToolbar` 서식 섹션 (채택) vs 행 컨텍스트/surface popup (기각)** — `/` 상단 툴바 고정 parity. popup은 surface 표시 로직 추가.
- **서식 액션 composite `toolbarActions` 노출 (채택) vs `sheet-body` 핸들러 누적 (기각)** — dev.9 composite·R5. 거대 UI 누적 금지.
- **토글 표시 `aria-pressed`·variant (채택) vs class `on` 이식 (기각)** — React 상태 표기. class 이식은 구현 디테일.
- **다중/단건 분기 현행 `useSheetClipActions` 내장 (채택) vs toolbar 분기 (기각)** — toolbar는 조립만.
- **IME typing surface 신호 `isEditSurface` (채택) vs `isEditing`/`mode`만 소비 (기각)** — typing 경로에서 `setMode('edit')`가 유예되어 toolbar ON이 늦음. `beginEditFromTyping`에서 surface 신호만 즉시 true, Esc는 즉시 OFF.
