# 2.9.0-dev.17 — 자막 import/export 모달 · 다중 탭 zip · 인코딩 영속

브랜치: `feat/subtitle-io-modal` — `24a4170` 통합선 머지. `SubtitleIoPanel`(dev.7 Verify용 최소 UI)을 폐지하고 툴바 트리거 + DialogShell 모달 2개로 전환한다. Remaining의 **풀 import/export 모달** 달성.

`VERSION` / tag는 **React 완전 변환 완료 시** `2.9.0`으로만 반영한다.

### Decision

- **DialogShell 모달 (채택) vs Panel 유지 (기각)** — dev.13 dialog 셸 + dev.10 i18n 셸 기반. Panel은 Verify용 최소 UI로 dev.7 범위. Remaining의 모달을 S6/S7에 넣기로 한 사용자 확정대로 진행.
- **인코딩 localStorage 개별 키 영속 (채택) vs store persist 래퍼 단일 (기각)** — 레거시 `smiEncode`·`srtEncode`·`smiEncodeFile`·`srtEncodeFile`·`vttEncodeFile` 개별 키 승격. `createStorage`가 persist `{ state }` → 개별 키 분해 저장. corrupt는 기본값, quota/private mode 무시.
- **`SmiMeta` shared 정본 (채택) vs 슬라이스 인라인 (기각)** — 시트 탭 영속 필드(`smiName`·`smiLang`)·`ExportWorkbookTab`·스토어·모달이 공유. `SavedSheet extends SmiMeta`.
- **uppercase 포맷 lookup 정본 (채택) vs lowercase 키 매핑 (기각)** — `SubtitleFormatUpper`·`SubtitleExportFormatUpper`·`toUpperFormat`/`toUpperLocale`로 `EXTENSION_BY_FORMAT`·`ENCODING_KEY_BY_FORMAT`·`LOCALE_TO_SMI_CLASS_KEY` 키 통일. UI value는 소문자 유지.
- **다중 탭 zip (채택) vs 단일 파일만 (기각)** — smi/srt/vtt 다중 선택 시 zip. json/excel은 선택 탭 전체(기존 워크북 경로).
- **SMI Class 로케일 프리셋 (채택) vs 고정 KRCC (기각)** — `localeSmiPreset(locale)` → KRCC/ENCC/JPCC. 탭 메타 비우면 로케일 프리셋.

### Notes

- 다중 탭 zip은 자체 zip 스토어(무압축) reuse. 파일명 충돌은 순번 접미.
- 스토어 분리: `useSubtitleIoStore` = `create()` **도메인 분리**. `partialize`는 인코딩 5필드만, `name` `subtitleIo`는 persist payload marker이며 실제 저장은 `createStorage()`가 localStorage 개별 키 5개로 분해. 시트 데이터·포맷 스토어와 무관.
- import는 `.smi`·`.srt`만. export는 SMI/SRT/VTT/JSON/Excel + zip.
- 스타일 제거(SRT/VTT)는 dev.7 `stripTagsKeepBr` 그대로.
