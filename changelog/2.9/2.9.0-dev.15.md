# 2.9.0-dev.15 — 커스텀 키 설정 UI · 엔진 계층 재구성

브랜치: `feat/shortkey-custom-settings` — `39ba303` 통합선 머지. `/edit/settings` Dialog에 단축키 설정 UI(커스텀 변경 폼 + 고정 kbd 라벨)를 올리고, shared 엔진을 engine/input/label 계층으로 분리한다.

`VERSION` / tag는 **React 완전 변환 완료 시** `2.9.0`으로만 반영한다.

### Decision

- **고정/커스텀 분리 `CUSTOM_SHORTKEY_IDS`(13) · `FIXED_SHORTKEY_IDS` (채택) vs 전 키 커스텀 (기각)** — 고정키 변경 시 네비·에딧 붕괴 위험. `setMask`·영속은 커스텀 id만 허용.
- **커스텀에 `search` 포함 (채택) vs 고정 (기각)** — 사용자 조정 필요 (잠김).
- **변경 상태 패널 소유 (채택) vs 행별 로컬 state (기각)** — Esc 게이트가 Radix capture(Dialog.Content.onEscapeKeyDown)의 패널 수준.
- **shared 엔진 engine/input/label 계층 분리 (채택) vs mask.ts 단일 파일 (기각)** — `modifiers`·`convert`·`is-ime-event`·`mask-label`로 SRP. `default-sheet-shortkey-masks.ts` → `model/keys/masks.ts`·`ids.ts`·`labels.ts` 재배치.
- **표시 분기 `pickPrimaryMask` (채택) vs ctrl/meta 양쪽 병기 (기각)** — Mac ⌘ / 그 외 Ctrl 하나만 (VS Code·Figma 관례).
