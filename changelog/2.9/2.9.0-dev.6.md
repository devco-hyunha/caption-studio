# 2.9.0-dev.6 — shortkey 상수 맵 · 탭 scroll 복원

브랜치: `refactor/shortkey-mask-naming` · `fix/edit-sheet-scroll-restore` (베이스 `feature/tanstack-start`).

`VERSION` / tag는 **React 완전 변환 완료 시** `2.9.0`으로만 반영한다.

### Decision

| 게이트 | 채택 | 대안 | 이유 / 기각 | 상태 |
|--------|------|------|-------------|------|
| shortkey 상수 형태 | `SHORTKEY_IDS` / `SHORTKEY_MASKS` / `SHORTKEY_PLACEHOLDERS` / `SHORTKEY_TYPES` 맵 | 개별 `SHORTKEY_ID_*` + 배열 이중 export / 문자열 리터럴 유지 | UPPER_SNAKE 키·단일 출처. 호출부는 맵 property | 잠김 |
| 탭 scroll 복원 | `useLayoutEffect` 2패스 (윈도 커밋 → 다음 layout에서 `scrollTop`) | `useEffect` 복원 유지 / layout 중 `flushSync` | paint 전 높이 확보. `flushSync`는 lifecycle 중 flush 금지 | 잠김 |

### Changed

- `default-sheet-key-masks.ts` → `default-sheet-shortkey-masks.ts` — id/mask/placeholder/type을 `SHORTKEY_*` 맵으로 통일
- `bind-sheet-keys` · store · Public API — 맵 상수 직접 참조 (`SHORTKEY_IDS.*` 등)
- `use-sheet-window` — 탭 전환 시 `pending` 복원: totalHeight 반영 후 `scrollTop` 적용, 클램프 시 윈도 재커밋

### Notes

- 키 mask 값·동작은 동일 (네이밍·구조만)
- 시트별 `scroll`은 런타임만 (영속 제외 유지 유지)
- `public/**` 미수정

### Verify

- `/edit` 단축키(Tab·화살표·Page·F2/Esc·Ctrl+Z/Y 등) 동작 동일
- 시트1 스크롤 후 시트2 → 시트1 — 빈 뷰 없이 스크롤 위치·행 복원
- 콘솔에 `flushSync` lifecycle 경고 없음
- `pnpm test:run` — shortkey · sheet 관련 통과
