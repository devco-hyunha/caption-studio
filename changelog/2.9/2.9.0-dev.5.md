# 2.9.0-dev.5 — Sheet 검색 · undo/redo 세션

브랜치: `feat/edit-search-undo` (베이스 `feature/tanstack-start`) — `/edit` 검색 점프 · 탭별 undo/redo · Ctrl+Z/Y.

`VERSION` / tag는 **React 완전 변환 완료 시** `2.9.0`으로만 반영한다.

### Decision

| 게이트 | 채택 | 대안 | 이유 / 기각 | 상태 |
|--------|------|------|-------------|------|
| undo/redo 상태 | 영속과 분리된 세션 스토어 (탭별 스택, 레거시 `editHistory` parity) | 시트 persist에 스택 포함 | FSD 세션 vs 영속 분리 · 잠긴 뷰 비영속 | 기본채택 |
| 검색 상태 | 세션 UI만 · 점프는 시트 포커스 API | 검색 결과 영속 | 뷰 상태 비영속 | 기본채택 |
| 키 | shortkey에 Ctrl+Z/Y 핸들러 추가 | 검색 패널·시트 전용 keydown | 키보드 진입=shortkey | 잠김 |
| history push 대상 | 셀 update · 행 insert/remove · multiple 서식(B/I/U) | 셀만 / 모든 스토어 액션 자동 | 레거시 `edit.log` 대상과 동등 | 기본채택 |
| 검색 UI | Verify용 최소 패널(쿼리·prev/next·건수) · 셸 검색은 후속 | 이번 작업에 풀 검색 셸 | 수동 Verify 필요. i18n·툴바 셸은 후속 | 잠김 |

### Added

- `features/sheet-session` — `edit-history` · `apply-history-entry` · `sheet-search` + Vitest
- `useSheetSessionStore` — 탭별 history 스택 · 검색 hits/current · 패널 open/close
- `SheetSearchPanel` — Verify용 검색 UI (쿼리 · 건수 · prev/next)
- shortkey — Ctrl+Z / Ctrl+Y 마스크·핸들러
- entity — history apply용 mutate 보조 · 셀/행/서식 경로에서 `pushHistory`

### Changed

- `use-sheets` / `sheet-body` — 탭 CRUD 시 history 스택 동기화 · 셀 커밋·insert/remove·B/I/U 시 history push
- 검색 점프 — 매치 셀로 포커스 이동 · 탭 전환 시 searchHits 초기화 (레거시 `restoreView`)

### Notes

- undo 스택 · 검색 결과는 디스크 제외 (세션만)
- 툴바/i18n 셸 검색 · subtitle I/O · video 키 · 커스텀 키 UI는 미포함
- `public/**` 미수정

### Verify

- 셀 수정·행 추가/삭제·B/I/U 후 Ctrl+Z / Ctrl+Y로 되돌리기·다시 적용 (`/` parity)
- 검색 쿼리 → 매치 건수 · 다음/이전 → 해당 셀 포커스
- undo 후 시트 화면과 영속 timelines 일치 (스택 자체는 디스크에 없음)
- 탭 전환 시 스택 분리 (레거시 탭별 history)
- widget에 `window` keydown 없음
- `pnpm test:run` — history push/pop · search match · apply-history 통과
