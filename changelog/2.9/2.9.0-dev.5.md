# 2.9.0-dev.5 — 시트 검색 패널 · error-search · `/` 단축키

브랜치: `feat/edit-sheet-search` — `/edit` React 시트에 **자막 검색 패널**(text/memo 매치·prev/next·결과 `n/m`)·**error-search**·**`/` 단축키 토글**·**히트 셀 하이라이트**를 이관한다. (`/` `search.js` parity)

`VERSION` / tag는 **React 완전 변환 완료 시** `2.9.0`으로만 반영한다.

### Decision

- **검색 로직은 feature 순수 함수** — `findSearchHits`(text/memo `toLowerCase().search`)·`stepSearchIndex`·`canSearchPrev/Next`·`findErrorHits`·`countErrorRows`. widget은 시트 포커스 API와 조립만 (`useSheetSearchActions`)
- **패널은 sheet-head 위 슬롯 portal** — `sheet-panel`에 `sheet-chrome` 슬롯, `SheetBody`가 toolbar을 portal로 조립·toolbar가 검색 패널 렌더(`search` props)
- **`/` 단축키(mask `?` → code `Slash`)** — 열릴 때 input focus는 패널 `useEffect`로 통일(버튼·단축키 공용). search input 포커스 중 `checkIsInput`이 true라 시트 키 발화 안 함(검색어 입력). 에딧 중 `toggleSearch` 차단·printable-edit `Slash` 제외(타입 투 리플레이스 미발화)
- **에딧·mutate 직전 `closeSearchPanel`** — selection(삽입·삭제)·clip(서식·클립)·time(±jump)·cell editor(에딧·typing 진입). `searchInputFocused` 중 typing 에딧 진입 차단. `SheetBody` stable wrapper(`closeSearchPanel`·`isSearchInputFocused`)로 공유 — search-actions 결과에서 제거
- **error-search**: 체크 시 hits를 errorRows(starttime col)로 대체·input·찾기 disabled. 해제 시 빈 hits
- **히트 셀 하이라이트** `bg-[#ffff95]`·`data-search`, current(`bg-sky-100`)가 search 위에. 렌더에 없는 행/열은 `getEditableColumn`으로 제외
- **포맷별 editable col** — SMI text=1/memo=2, SRT text=2/memo=3 (`TEXT_MEMO_COLS`)
- **탭 전환·CRUD 시 `clearSearchHits`** (`useSheets`)
- **`SheetSearchStore` 타입 `types.ts` 분리** — 스토어 파일 인라인 금지 (`use-shortkey-store`·`use-sheet-store` 컨벤션)

### Notes

- 검색 토글 키는 `/`(Slash code). mask token `?`는 `/`(Shift 없음)·`?` 모두 Slash code 매칭. search input 포커스 중 `/`는 시트 키 발화 안 함
- Enter submit은 form submit 정상(찾기 버튼·Enter). fast typing은 React `onChange`를 거치지 않아 submit 타이밍이 어긋날 수 있음
- error-search hits는 starttime col. prev/next 경계 클램프
