# 2.9.0-dev.1 — TanStack Start 세팅

브랜치: `feat/tss-setup`

Vite + React + TanStack Start 앱 골격을 도입하고, 하이브리드 폰트·FSD 자리·도구 체인을 맞춘다.  
`/`는 레거시 Caption Studio, `/edit`는 이후 도메인 이전용 껍데기다.

`VERSION` / tag는 **React 완전 변환 완료 시** `2.9.0`으로만 반영한다. (현재 릴리스: `2.8.4`)

### Added

- TanStack Start + Vite + React + TypeScript 앱 (`src/`)
  - 라우트: `/`, `/edit`, `/dev/fonts`
  - `shared/config` (env), `shared/lib`, `shared/ui`
  - `widgets/caption-shell`, `pages/not-found`
  - `app/styles` — 글로벌 CSS
- `src/app/styles/fonts.css`
  - 패밀리 분리 하이브리드 스택: `'Pretendard Suit-num'`(SUIT 숫자) + `'Pretendard'`(한글/영문) + `'Pretendard JP'`(일본어)
  - SUIT Variable 숫자(`0-9`) 및 타임코드 구분자(`:`, `,`, `.`) 전용 `unicode-range`
  - Pretendard / Pretendard JP Latin 서브셋에서 숫자 중복 범위 제거
- ESLint · Prettier · Vitest · `.env.example` / `.env.development` / `.env.production`

### Changed

- 앱 진입을 Vite(`pnpm dev`) 기준으로 전환. 1차 정적 셸은 `index.legacy.html`로 보관 (빌드 미포함)
- `src/app/styles/app.css`
  - `--font-sans`: `'Pretendard Suit-num', 'Pretendard', 'Pretendard JP', …` 스택
  - `html` 기본 OpenType: `tnum` + `ss18` (`ss17` / `zero` / `ss01` 미사용)
- 폰트 시편: `/edit` → `/dev/fonts`, `/edit`는 편집 화면 껍데지
- `src/` 함수 스타일: 화살표 통일 · 다중 export만 `const` + `export { … }`
- FSD 자리 정리: `lib`→`shared/lib`, `components/ui`→`shared/ui`, 셸→`widgets`, 404→`pages`, `styles`→`app/styles`
- `package.json` — `@sun-typeface/suit`, `pretendard`, `pretendard-jp` 등
